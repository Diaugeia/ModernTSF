# LSINet

## Key ideas

- `SharedSparseConnectionRouter` (`sparse_connection_router`) builds one 0/1 interaction matrix per head over time patches from a learnable memory table, not from the input, with a top-k hard mask (`density`).
- `SparseTemporalInteractionBlock` combines a time-invariant patch-mixing MLP, propagation of per-head values through the shared sparse matrix, a time-updating MLP, and a feature-integration MLP with residuals.
- Patches have a learnable position embedding (`positional_encoding`); channels are folded into the batch so every sample and channel reuses the same connections.
- `FlattenForecastHead` maps patch features to the horizon inside `revin`; the paper's auxiliary sparsity loss is not wired in.

## Differences

**Clean-room implementation: confirmed.** The linked `NOASSERTION` repository is `reference-only` and was not copied; structural and runtime evidence is generated by `uv run tsf model verify LSINet`. Recorded, deliberate differences from the paper/official code:

- **No auxiliary training loss.** The paper's self-adaptive sparse regularization loss (ASRL, Eq. 7 — a BCE term between the router's soft edge probabilities and an intermittently refreshed top-K target) is a training-time regularizer over parameters, not part of the point-forecast computation. Because the fixed four-input `forward` contract returns only the forecast tensor, ASRL is not wired into `forward`; the router still enforces sparsity at inference through its top-k hard mask, so the defining sparse-interaction behavior is preserved even though the auxiliary loss term itself is omitted.
- **Two-class Bernoulli collapsed to a single logit.** The paper (Eq. 3-4) forms a two-way softmax `{c^0_ij, c^1_ij}` per patch pair. The implementation scores each pair with one logit and reads it through `sigmoid`/binary-Gumbel noise, which is the standard, mathematically equivalent binary-concrete reparameterization of a two-class softmax with one class fixed at zero; no expressiveness is lost, but the tensor shapes differ from the official code's `[..., 2]` logits.
- **Memory-to-head reshape uses a conventional per-head split**, not the official code's `.view(n_heads, num_patches, -1)` reinterpretation of a `(num_patches, n_heads * d_model)` buffer (which mixes the patch and head axes in the flat memory layout rather than assigning one contiguous `d_model` slice per head per patch). The paper's text and Fig. 3(b) describe one `d_model`-sized embedding per patch per head; the local `SharedSparseConnectionRouter` reshapes/permutes so each head consistently owns its own slice of the per-patch memory embedding.
- **No ablation branches.** The official repository's `Self_Attention_Mechanism` (SAM) ablation swap and the `resdual_block` extra-MSIM-residual ablation are both training-script flags outside the paper's Fig. 3 architecture (SAM is an alternative to MSIM used only in Table 3's ablation, `resdual_block` defaults off in the released training script). Neither is implemented; LSINet here is the single Fig. 3a architecture with `e_layers` stacked STI modules, matching the paper's stated single-STI-module default on all reported datasets (`e_layers=1`).
- **Individual/variable-decomposition forecast heads omitted.** The official `Flatten_Head` also supports a per-channel (`individual`) and a variable-group-decomposition (`var_decomp`) head; TSFLab's `flatten_forecast_head` component covers the shared and per-channel (`individual`) cases used in the paper's main results and omits the variable-decomposition ablation path.
- **New shared component.** `sparse_connection_router` (`SharedSparseConnectionRouter`) is extracted from LSINet's Multihead Sparse Interaction Mechanism as a paper-neutral "shared, input-independent sparse adjacency over N discrete positions" building block (position-memory table -> pairwise relational MLP -> top-k/Gumbel discretization), reusable by any future patch-, token-, or node-mixing model that wants a learned sparse routing matrix which does not depend on the batch input. LSINet is currently its only consumer.
- Marks and decoder arguments are accepted and ignored, consistent with LSINet's non-covariate design in the paper and official code.

## Abstract
Recent work shows that linear models can outperform several transformer models in long-term time-series forecasting (TSF). However, instead of explicitly performing temporal interaction through self-attention, linear models implicitly perform it based on stacked MLP structures, which may be insufficient in capturing the complex temporal dependencies and their performance still has potential for improvement. To this end, we propose a Lightweight Sparse Interaction Network (LSINet) for TSF task. Inspired by the sparsity of self-attention, we propose a Multihead Sparse Interaction Mechanism (MSIM). Different from self-attention, MSIM learns the important connections between time steps through sparsity-induced Bernoulli distribution to capture temporal dependencies for TSF. The sparsity is ensured by the proposed self-adaptive regularization loss. Moreover, we observe the shareability of temporal interactions and propose to perform Shared Interaction Learning (SIL) for MSIM to further enhance efficiency and improve convergence. LSINet is a linear model comprising only MLP structures with low overhead and equipped with explicit temporal interaction mechanisms. Extensive experiments on public datasets show that LSINet achieves both higher accuracy and better efficiency than advanced linear models and transformer models in TSF tasks. The code is available at the link https://github.com/Meteor-Stars/LSINet.
