# smoke

## Overview

`smoke` is a tiny deterministic CSV for CI and CPU smoke runs. `scripts/make_smoke_data.py` writes five channels of daily plus weekly sinusoids with noise and a noisy cosine `OT` (seed 0), at hourly timestamps. It exists to exercise the whole pipeline in seconds; metrics on it say nothing about model quality.

## Provenance and license

- Generated by `scripts/make_smoke_data.py`; no external source. Regenerate with `uv run python scripts/make_smoke_data.py` (it also rewrites the synthetic `cauair_ccaq` fixture).
- Covered by the repository MIT license; there is nothing to cite.

## Standard protocol and known pitfalls

- With 400 rows and a 6:2:2 split, the validation and test splits hold 80 rows each; keep `seq_len + pred_len` well below 80 (the contract fixtures use 24 and 24) or a split yields no window.
- Seasonality is artificial and noise-free in structure, so even weak models fit it; use it to check shapes, losses, and plumbing only.
- It uses the `weather` loader (a CSV loader with a date column), not a dataset-specific one.
